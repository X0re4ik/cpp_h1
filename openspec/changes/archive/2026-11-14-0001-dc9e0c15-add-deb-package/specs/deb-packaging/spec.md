# Spec Delta

## Purpose

Дистрибуция приложения h1 в виде deb-пакета: пользователи Ubuntu 22.04/24.04
получают готовый бинарник без сборки из исходников, установка выполняется
командой `apt-get install ./h1_*.deb`.

## ADDED Requirements

### Requirement: Сборка deb-пакета из CMake-проекта
Проект SHALL предоставлять способ собрать deb-пакет одной командой из
конфигурированной CMake-сборки без ручных правок метаданных. Имя пакета —
`h1`, версия пакета SHALL повторять версию проекта (`project(h1 VERSION ...)`),
архитектура — amd64.

#### Scenario: Сборка пакета
- **WHEN** разработчик конфигурирует и собирает проект (cmake + cmake --build) и запускает сборку пакета
- **THEN** в каталоге сборки появляется файл `h1_<версия>_amd64.deb`

#### Scenario: Версия пакета соответствует версии проекта
- **WHEN** версия проекта в CMake меняется
- **THEN** имя и версия собранного deb-пакета обновляются автоматически, без правки метаданных пакета

### Requirement: Состав пакета
Пакет `h1` SHALL устанавливать только исполняемый файл приложения в
`/usr/bin/h1`. Заголовки, статическая библиотека `h1_core`, тесты и
сервисные файлы (env, docker-compose) в пакет НЕ входят.

#### Scenario: Бинарник доступен в PATH
- **WHEN** пакет установлен
- **THEN** команда `h1` доступна в PATH и `h1 --help` выводит справку

#### Scenario: В пакете нет посторонних файлов
- **WHEN** пользователь просматривает содержимое установленного пакета
- **THEN** в пакете присутствует только `/usr/bin/h1` (плюс штатные служебные записи dpkg)

### Requirement: Зависимости пакета
Пакет SHALL объявлять `Depends: libpq5` и НЕ объявлять зависимостей от
FetchContent-библиотек (spdlog, nlohmann/json, argparse, libenvpp) — они
должны быть линкованы статически. PostgreSQL-сервер не является зависимостью:
БД может быть внешней.

#### Scenario: Установка разрешает зависимости
- **WHEN** пакет устанавливается на системе Ubuntu без локального PostgreSQL-сервера
- **THEN** установка выполняется успешно; apt при необходимости устанавливает только `libpq5`

#### Scenario: Отсутствие сетевого доступа к БД не ломает установку
- **WHEN** пакет установлен на машине без работающего PostgreSQL
- **THEN** установка завершается успешно; сообщение об ошибке подключения появляется только при запуске приложения с операцией, требующей БД

### Requirement: Установка через apt-get на целевых платформах
Пакет SHALL корректно устанавливаться командой
`apt-get install ./h1_<версия>_amd64.deb` на Ubuntu 22.04 LTS и Ubuntu 24.04
LTS (amd64), включая удаление `apt-get remove h1` без оставшихся файлов.

#### Scenario: Установка на Ubuntu 22.04
- **WHEN** пакет устанавливается через `apt-get install ./h1_*.deb` на Ubuntu 22.04 amd64
- **THEN** установка завершается без ошибок, `/usr/bin/h1` на месте и запускается

#### Scenario: Установка на Ubuntu 24.04
- **WHEN** пакет устанавливается через `apt-get install ./h1_*.deb` на Ubuntu 24.04 amd64
- **THEN** установка завершается без ошибок, `/usr/bin/h1` на месте и запускается

#### Scenario: Удаление пакета
- **WHEN** выполняется `apt-get remove h1`
- **THEN** `/usr/bin/h1` удаляется, пакет исчезает из списка установленных

### Requirement: Установленный пакет работает как приложение из репозитория
Установленный пакет SHALL вести себя идентично приложению, собранному из
исходников: поддерживает `--help`, `--verbose`, `--config` с JSON-операцией,
выводит результат в ожидаемом формате и записывает историю в доступный
PostgreSQL.

#### Scenario: Расчет через установленный бинарник
- **WHEN** после установки выполняется `h1 --config '{"left": 2, "right": 3, "operation": "+"}'`
- **THEN** вывод совпадает с выводом приложения, собранного из исходников (например `2+3=5.00`)

#### Scenario: Ошибка вычисления
- **WHEN** выполняется операция с ошибкой (например деление на ноль)
- **THEN** сообщение об ошибке выводится в stderr, как в версии из исходников
