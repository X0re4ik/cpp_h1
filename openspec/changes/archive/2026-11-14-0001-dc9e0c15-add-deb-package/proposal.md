# Proposal: add-deb-package

## Why

Сейчас приложение распространяется только в виде исходников: чтобы получить
`h1`, нужно клонировать репозиторий, ставить через FetchContent внешние
зависимости и компилировать на месте. Это медленно и неудобно. Нужен
готовый deb-пакет, который можно установить на Ubuntu 22.04/24.04 командой
`apt-get install ./h1_*.deb` — apt сам разрешит зависимости.

## What Changes

- Добавляется сборка deb-пакета прямо из существующего CMake через **CPack**
  (`cpack -G DEB`), без создания отдельного каталога `debian/`.
- Пакет `h1` ставит только исполняемый файл `/usr/bin/h1`. Заголовки,
  библиотека `h1_core` и тесты в пакет НЕ входят.
- FetchContent-зависимости (spdlog, nlohmann/json, argparse, libenvpp)
  линкуются статически в бинарник — внешние зависимости пакета не включают их.
- Динамическая зависимость только на libpq: `Depends: libpq5`
  (версия, совместимая с Ubuntu 22.04 и 24.04).
- Метаданные пакета: имя `h1`, версия из `project(h1 VERSION 1.0)`
  (формат `1.0-<release>`), архитектура amd64, секция utils,
  поддержка `dpkg -i` / `apt-get install ./h1_*.deb`.
- Целевые платформы: Ubuntu 22.04 LTS и Ubuntu 24.04 LTS, amd64.

## Capabilities

### New Capabilities

- `deb-packaging`: поведение дистрибуции приложения — сборка deb-пакета
  из CMake-проекта через CPack, состав пакета (только `/usr/bin/h1`),
  метаданные (имя, версия, архитектура), зависимости пакета (`libpq5`)
  и установка через `apt-get install ./h1_*.deb` на Ubuntu 22.04/24.04.

### Modified Capabilities

- (нет — `openspec list --specs` пуст, существующих capabilities в проекте нет)

## Impact

- `CMakeLists.txt` — добавляется секция CPack (CPACK_*, установка бинарника
  через `install(TARGETS h1 RUNTIME ...)`) и, при необходимости, Makefile target
  `package`.
- Сборка пакета требует установленного `cpack`/`dpkg-deb` (есть в Ubuntu по
  умолчанию) и по-прежнему FetchContent-зависимостей на этапе компиляции.
- Существующее поведение приложения и тестов не меняется; README дополняется
  разделом «Сборка deb-пакета».
